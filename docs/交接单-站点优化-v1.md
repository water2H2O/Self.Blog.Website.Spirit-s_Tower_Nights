## 3. 改动详情

### A. 首屏定位语

**现状**：`src/pages/index.astro:1039` 直接 `<h1>水水</h1>`，下面接个人介绍。陌生访客滑到第三个卡片才知道这是《水塔夜谈》的站。

**目标**：H1 下方插入一行定位语，文案**逐字使用**：

```
欢迎来到水塔——一个属于水水的，原创的 OC 世界观
```

**要求**：
- 视觉上作为 H1 的副标题（字号小于 H1，颜色弱于正文标题，行高 1.6 左右）；
- 与个人介绍段落之间留出间距，不要贴死；
- 移动端不换行折断成两行以上（可用 `text-wrap: balance` 或缩小字号）。

**验收**：首页首屏（1440×900 与 390×844 两种）截图可见该行完整、不被截断；不影响下方模块位置。

### B. 「不 · 郑 重 申 明」

**现状**：`src/pages/index.astro:1184-1201`，组件类名 `notice-lead`，文案 `郑 重 声 明`。是一段**玩梗**内容（"本站无 PHP""放心把 API key 交给我""每周四充 50"）。

**目标**：
1. 标题文案改为：`不 · 郑 重 申 明`（中间是间隔号 `·`，两侧各一个半角空格）；
2. 视觉上更"显眼"——建议方向（任选其一，不要都做）：
   - 加一条醒目的边框/底色条，让它看起来像"正式横幅"而不是小字注释；
   - 或用衬线体 + 字距加宽 + 一条横线，做出"公告"感；
3. 保持玩梗语气，**不要**加"以下纯属玩笑"之类的前置说明（末尾已有的"以上纯属玩梗"保留）。

**验收**：截图确认新标题与样式；页面无横向滚动条；移动端不溢出。

### C. 全站搜索

**现状**：无搜索。`/search/` 返回 404。内容量：`stories` 59 篇、`textbook` 31 篇、`lore` 18 篇、`races` 13 篇、`characters` 10 篇、`eden` 9 篇、`blog` 6 篇。

**目标**：输入关键词能命中标题、摘要（frontmatter 的 `summary`）与正文，结果可点击直达，中文可用。

**两条实现路线（二选一，先做前者）**：

| 路线 | 做法 | 优点 | 风险 |
|---|---|---|---|
| **C1 自建 JSON 索引**（推荐先做） | 构建时把每篇的 `title / summary / tags / 正文纯文本 / url / 所属目录` 导出成 `dist/search-index.json`；`/search/` 页面加载该 JSON，做**子串 + 拼音首字**匹配，结果高亮 | 零依赖、中文可控（直接 substring）、体积可控（约 200–400 KB gzip 后） | 内容再多要分片加载 |
| **C2 Pagefind** | `npm i -D pagefind`，`build` 后跑 `pagefind --site dist`，用其 UI | 成熟、支持分页与高亮、增量构建 | **中文分词需实测**（见 §7 线索），Astro 7 兼容性需验证 |

**硬要求**（两种路线共用的验收）：
- 搜索页路径 `/search/`；
- 输入"晶脉""瘴素""奥法联合"这类专名能命中；
- 结果条目标出所属分类（世界观 / 故事 / 随笔）；
- 无结果时给出友好提示 + 建议入口；
- 搜索页在导航里**可发现**（建议放在「站点导航」末尾，或 H1 区加一个小放大镜图标，别占一级菜单位）。

## 5. 待决策：世界观是否拆到子域名

**问题**：内容体量已大（160 篇 / 135 万字），要不要把世界观引流到 `worldview.water2h2o.com`？

**行业惯例（供判断）**：

| 场景 | 通常做法 | 原因 |
|---|---|---|
| 个人身份 / 作品集 | 主域名 + 子目录 | 权重集中，一条流水线 |
| 独立产品、文档、团队 | 子域名（`docs.` / `blog.`） | 独立发布节奏、独立技术栈 |
| 同一作者的内容分区 | **子目录 + 独立视觉**（"站中站"） | 用户感知独立，SEO 不分散 |

**建议（本轮不实施，等主人拍板）**：

优先做 **站中站**：`/worldview/` 路径不变，但换一套布局组件（导航、配色、面包屑），做出"进了另一个站"的感觉。理由：

- 世界观是主站**最强的内容**，拆走会让主站变薄；
- 子域名会让搜索引擎视为两个站，外链与权重分散，需要维护两套 sitemap + canonical 互指；
- 站中站能拿到 80% 的拆分收益，成本约 10%。

**真该上子域名的时机**：世界观要独立对外（出版、合作、独立团队）、需要独立技术栈、或有独立品牌名（如 `tower.water2h2o.com`）。

**若最终决定拆**，迁移清单（缺一不可）：
1. 全量 301：`/worldview/*` → `https://worldview.water2h2o.com/*`；
2. 两套 sitemap，互相在 `robots.txt` 声明；
3. 新站页面 `canonical` 指向新域名；
4. 主站保留 `/worldview/` 落地页（保留入口与摘要，不要 404）；
5. 搜索索引分别构建（C2 需要两套 Pagefind 产物）；
6. 监测 30 天：老链接 404 率、搜索排名变化。
