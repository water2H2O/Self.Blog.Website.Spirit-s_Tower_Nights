2026 年 10 月 11 日

域名买下来了，`water2h2o.com`。一开始还在纠结备案，后来才知道备案只跟「服务器在不在大陆」有关 —— 主机放境外就完全不用。于是把 DNS 托管到 Cloudflare，站也挂在那边。

中间踩了几个坑，记一下，免得下次又忘。

**一、Pages 变成了 Workers。** 控制台里点「创建应用」，进去的是新的 Workers 流程，部署命令是 `npx wrangler deploy`，不再是 Pages 那套。所以仓库里得放一份 `wrangler.jsonc`，把资源目录指到构建产物：

```jsonc
"assets": { "directory": "./dist" }
```

这个站不跑任何脚本，纯粹发静态文件，这样就够了。

**二、Node 版本要钉住。** 构建镜像默认的 Node 比我需要的低，不改的话第一步装依赖就会失败。仓库根目录放一个 `.node-version` 写上版本号就行，不用去控制台里翻环境变量。

**三、`http://` 不会自动跳 `https://`。** 这个开关 Cloudflare **默认是关的**，得手动去「SSL/TLS → 边缘证书 → 始终使用 HTTPS」打开。开之前 http 是能正常打开的 —— 也就是说有人会以明文浏览，浏览器还会在地址栏给他标一个「不安全」。

**四、换域名记得改 `site`。** canonical、sitemap、RSS 全靠它拼绝对链接，不改的话搜索引擎收录的全是旧地址。

---

另外顺便吐槽一句：浏览器现在**故意不显示** `https://`，Chrome 连锁头都取消了，换成一个调节滑杆样的小图标。所以地址栏看不到 https、也没有锁头，**不代表没加密** —— 点左边那个小图标，能看到「连接是安全的」才是准的。

现在这个站：自己的域名、不用备案、push 一下自动部署。代价是用不了大陆的 CDN，微信里被拦的风险也比备案域名高一些 —— 先这样吧。
