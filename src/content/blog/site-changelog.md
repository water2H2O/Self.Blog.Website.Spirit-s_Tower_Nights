## 2026-10-10　画廊改成图池 + 随机照片墙

把散在各个文件夹里的图全部收进一个图池（`public/gallery/`，147 张），画廊每次打开**随机抽 60 张**铺成照片墙，大小、横竖、顺序都随机，刷新即换。

- **不再按文件夹分组**，一整个池子混着铺
- 每张图右下角有页面水印（只在页面上叠加，右键另存的原图是干净的）
- 可以按 **原创设定 / 联动设定 / 其他** 筛
- **联动设定会标出设主** —— 别人家的孩子，版权归各设主所有
- 147 张全部逐张测过可访问

## 2026-10-10　回响之殿：7 首曲子全部上站

音乐作品的源文件是 273 MB 的 WAV，全部转成 MP3（192 kbps）后一共 **23.94 MB，省掉 91% 体积**。

每首曲子有自己的页面：

- 大图曲绘，进页面自动播放
- **底部固定播放条**，滚到哪都能暂停、拖进度
- 「小故事」—— 每首曲子配的那段文字
- 曲师与画师署名（曲师名可以点进主页）
- 想看 PV 就点播放条右边的按钮

顺带把曲师、画师、小故事和 PV 链接都补齐了 —— 这些原先散在各处，现在每首曲子一页写清楚。

## 2026-10-09　授权与使用说明

加了一页 <a href="/license/">《授权与使用说明》</a>，把话说清楚：

- **文字内容**（世界观设定、角色档案、故事正文）带 `CC BY 4.0` 标记 —— 署名就能转载、二创，甚至商用
- **音乐不开放** —— 全部是与曲师合作的委托 / 共创作品，版权由曲师和企划共同所有
- **委托插画**归原画师，**联动设定**归各设主

页脚也改成了对应的说法。

## 2026-10-08　正文入库：50 话，22.3 万字

第一幕 45 话 + 第二幕 5 话全部录进站内，逐字照搬，没有做任何改写。

阅读页有上一话 / 下一话，目录按「幕 → 篇 → 话」排。源文档里的软换行（Shift+Enter）也一并处理了，不然整章会挤成一大坨。

## 2026-10-07　目录调整：企划收进 `/worldview/`

原先企划内容占着根目录，现在整体收进 `/worldview/` 下面，根目录留给个人内容。进入企划区后页头会多出一条二级导航（总览 / 设定 / 种族 / 角色 / 故事 / 回响之殿 / 画廊），离开就消失。

## 2026-10-06　开站

用 Astro 搭的静态站，深色底 + 水色的光（`#AFFFFF`，淼渺的代表色）。

- 图片全部压缩成 WebP：源文件 382 MB → 12.7 MB
- 中文字体、手机端自适应、灯箱、深浅对比都调过一轮
- 部署走 GitHub Pages
