## 六条轴，怎么排

本册的六轴教学模型统一写作：

```text
q = (q火, q水, q地, q风, q草, q光)
```

简写 `{火:1, 水:2}`，就是其余坐标为零。正负号只记方向，不记善恶，也不是负数量的粒子。

| 名称 | 模型里的位置 |
| --- | --- |
| 火、水、地、风、草、光 | 各自轴的+1 |
| 暗 | 光轴−1 |
| 霜、冰 | 火轴−0.5、−1 |
| 砂、金 | 水轴−0.5、−1 |
| 芽、木 | 地轴−0.5、−1 |
| 电 | 草轴−0.5 |
| 烬 | 光轴−0.5 |
| 晨、影 | 光轴+2、−1.5；作为拓展阅读 |

这张表是本稿选用的表征，不是已测定的自然常数。没有列出来的对象，先留空，不凭名字补坐标；衍生元素也不因此变成一年级的独立实操内容。

## 净值和投入，翻账时别看错栏

只有在同一参照、同一混合域且允许线性近似时，才这样合并：

```text
q净 = Σj qj
I(q净) = Σi |q净,i|
A_in = Σj Σi |qj,i|
```

i依次指六条轴，j依次指合并前的各份投入。I看合并后还留下多少定向分量；A_in看原来投入了多少模型当量。先加再取绝对值，与每份先取绝对值再相加，记的是两件事。

> **［纸上算一遍］**
>
> 一份火是+1，一份冰是−1，都在火轴上。净值是0，I也是0，可A_in仍是2。你没有因此得到“什么都没投，也没有余热和残余”的结论。草和木更不能抵消：草在草轴，木在地轴的负向，不在同一条轴上。

需要分配资源时，还可以用一张另外的账：

```text
A_in = B + L + R
B：有效输出当量
L：损耗分配当量
R：已经投入、仍待处理的残余当量
```

账里仍要记清实际投入了什么。分主料、辅料、态料，是为了认清用途，不是让某一种投入凭空免记；态料也不能因为兼有控制用途，就被重复算成一份额外供能。同一核算边界里，这三栏互不重复。第七章若写作A_out、A_loss、A_res，依次就是B、L、R。它们仍是统一标度下的模型账，不是元素、魔力和真实热量之间的兑换表。尚未投入的预留材料另放一边，不算R。

## 忘了写什么，照这一页查

下面是记录约定，不是要求你一字不差背下来的咒文，也不是已经核定的通用符文语法。

| 要补的一栏 | 问自己一句 |
| --- | --- |
| 主体与操作 | 谁负责，做什么？ |
| 对象与料 | 用哪一类元素，从哪里来，作用于哪里？ |
| 初始条件 | 元素场、时序参照、状态观测与自身状态，是否都合适？ |
| 触发 | 从哪件事算t₀？ |
| 等待 | 要不要等，等多久？ |
| 持续 | 从有效作用开始，维持多久？ |
| 范围 | 哪些地方能动，哪些地方不能碰？ |
| 提前停止 | 哪种变化出现就不再继续，怎样分辨它？ |
| 输入与连接 | 魔力怎样给，各段何时停给；连接需要维持到哪一步？ |
| 收场 | 按什么方式解除，还要观察什么，才能离开？ |

写复合申明时，再加几问：后一段等的是前一段开始、结束，还是另一条反馈？是否沿用同一目标？中途取消之后，已经发生的部分怎样处理？这些没有交代，“先做这个再做那个”仍然只是一个大意。
