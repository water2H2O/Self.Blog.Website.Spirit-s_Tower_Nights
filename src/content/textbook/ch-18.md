## 学习目标

- 能独立完成一个「条件触发式」法术，连续三次结果一致；
- 能在它不该继续的时候，看着它自己停下来；
- 能背出十三步的全流程清单；
- 能说出三门课合起来是一件事的哪三个侧面。
### 18.1　标准流程清单

这是全书的清单，元素、时序、状态三门都在里面。带「新」的是这一卷加的。

|  | 步骤 | 要点 |
| --- | --- | --- |
| 一 | 看地方 | 元素场四问 |
| 二 | 看时候 | 时序场三档。稳、晃、紧 |
| 三 | 看两半（新） | 环境状态 + 三句自查，取更差的一个 |
| 四 | 定档（新） | 合、将就、不该做。将就 → 按第二档办 |
| 五 | 写申明 | 四要素 + 启动、持续、终止 + 初始与目标状态（新） |
| 六 | 写约束（新） | 防不够/防过头/防改变/防自己，至少写两条 |
| 七 | 读一遍 | 找互相否定、顺序反了、嵌套点用了「过多久」 |
| 八 | 分段给 | 法术有几段，魔力就分几份 |
| 九 | 注入 | 匀速、慢给、看着给 |
| 十 | 收 | 按终止条件收。不许直接撒手，也不许伸手去扶（新） |
| 十一 | 再读一次（新） | 收场之后重新读状态。它是下一次的入场条件 |
| 十二 | 写三行 | 做了什么、发生了什么、身上哪里不舒服 |

这本书到这里，第一次把三门课摆进了同一张纸。

这套清单不是让你每次念一遍。 它是你出错时的排查路线：从第一步往下走，走到哪一步答不上来，问题就在那儿。

练到后来，前四步会合成一个动作——你走进一个地方，几息之内就知道今天能不能动手。那一天你就可以开始学下一级的东西了。

### 18.2　常见错误三种

| 类型 | 典型说法 | 该往哪儿查 |
| --- | --- | --- |
| 地方/时候不对 | 「同一个地方，上午成下午不成」 | 第五章、第十章、第十五章的三档。先分档 |
| 申明没写清 | 「成了但不是我要的」「该停的时候不停」 | 四要素、三段、初始与目标状态 |
| 给法/收场不对 | 「我又补了一份」「我扶了一下」 | 第七章、第十二章、第十七章。三步处置 |

顺序永远是从外往里：地方、时候、两半、申明，最后才怀疑自己。

三门课都读完，你应该明白这条顺序的道理了：排在前面的东西，都比你自己更容易查清楚。

### 18.3　综合练习：做一个「条件触发式」的法术

这是全书的结业题，也是三门课的合并题。

做法：做一个法术，它满足三件事——

1. 在对的时候开始（时序）；
1. 在条件不满足的时候自己停下来，不需要你动手（状态）；
1. 停下来之后，你能说出它是哪一条约束触发的（申明）。
过关标准：连续做三次；其中至少一次要由教习制造一个不该继续的情形，而你要看着它自己收场。

第三条是真正的关卡。多数人做到了前两条，但说不清是哪一条约束起的效——那说明约束是「顺手写的」，不是「想清楚写的」。

> ［塔里的事］ 这道结业题也改过。 早年的题目是「做出一个能自己停的法术」。结果交上来的东西里，有相当一部分是靠运气停的：条件碰巧满足了。 所以后来加了一条：你要能说出是哪一条约束起的效。 说不出来，就不算数。 知其然，还要知其所以然——这句话在塔里不是修辞，是评分标准。

## 本课小结

- 一套两半读法——环境与你自己，取更差的一个；
- 一个三档判断——合、将就、不该做，以及「第二档会成功」这件事；
- 一套状态写法——初始状态、目标状态、四条约束；
- 一句要背的话——自己喊停靠不住，写进去的停才靠得住；
- 一个收场习惯——停注入、不碰它、等它收完，然后再读一次。
