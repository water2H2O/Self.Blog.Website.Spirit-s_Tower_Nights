读完一卷后，如果愿意，可以拿这些话问问自己。不用交卷；想不清时，翻回相应的例子就好。

| 听起来顺口的话 | 再想一步 |
| --- | --- |
| “两团水一样大，消耗应该一样。” | 外观还没告诉你来源、投入与残余。第一、二卷。 |
| “净值归零，这次便没有代价。” | 净分量与原始投入是两栏。第二卷、第七章。 |
| “等两息，维持三息，所以第三息结束。” | 若触发为0、等待到2才起效，应到5结束；等待没占掉持续期。第三卷。 |
| “到了目标，就一定该停。” | 看申明如何规定；目标、正常结束与保护退出要分清。第四卷。 |
| “提前停了，就是没做好。” | 先看是否按保护条件退出，保护路径可能正好执行正确。第四卷。 |
| “每一段都是T6，接多少段也还是能做。” | 组合会带来新的整体功能与风险，不替你扩大权限。第五卷。 |
| “连续做成三次，算是弄懂原因了。” | 它提供重复证据，不自动解释原因，也不排除共同偏差。第二、三、五卷。 |
