这几页供你回头查，不必先背下来。解释刻意写得短，涉及实际用法时，仍回正文看例子。

| 词 | 在本册里说的是什么 | 容易混到一起的东西 |
| --- | --- | --- |
| 法则 | 世界运行、对象相互作用所遵循的规则 | 学院规程可以改，不代表法则也随之改了 |
| 元素粒子 | 可独立调用的最小元素单位 | 坐标中的0.5不是半个粒子 |
| 基础元素 | 地、水、火、风、草、光、暗七种既有分类 | 六轴是记法，不是重数一次元素种类 |
| 衍生元素 | 基础元素衰变链中的相关形态 | 知道名字不等于获准实际调用 |
| 死寂物质 | 已无可调用元素性质的终点状态 | 不代表物质消失或失去全部物理作用 |
| 魔力 | 参与法则读写、驱动执行的能量态与操作投入 | 不能当作水元素、材料质量或热量直接相加 |
| 料 | 可用元素构成及其载体、资源条件的简称 | 不是一切施法代价的总称 |
| 形 | 让料如何作用的安排，包括对象、范围、时序与停止条件 | 不只指看起来是什么形状 |
| 仪式 | 建立、检查执行条件的准备 | 不一定非有某种桌子或阵图 |
| 申明 | 把操作、对象、主体和约束说明白的可执行描述 | 愿望和咒语外壳都不能代替它 |
| 注入 | 向准备好的结构引入魔力，并留意反馈 | 不是把能用的魔力一口气全部倒进去 |
| 元素场 | 可调用元素在环境中的分布与可用条件 | 没有所有人共用的洁净度百分数 |
| 时序场 | 局部计时和事件衔接所需的环境条件 | 不等于随意改写时间本身 |
| 状态场 | 与执行相关的条件，以及这些条件能否被看见、分辨 | 不是包揽一切的万能检测器 |
| 主料、辅料、态料 | 分别承担主要类别、改变反应条件、编码控制参数等角色 | 三种角色不能不分用途便全加进同一份资源账 |
| 触发 | 约定过程进入某阶段的事件 | 触发时可能还没开始产生目标作用 |
| 等待间隔 | 触发后到有效作用开始前的一段时间 | 不包括有效作用本身的持续期 |
| 有效持续期 | 目标作用实际维持的那一段 | 不是从准备到残余消失的全部时间 |
| 目标状态 | 用来判断结果是否符合需求的标准 | 写下它不等于保证能做到 |
| 停止条件 | 让执行退出的约定条件 | 不代表已有影响立即全部消失 |
| 收场 | 停止后，让残余过程收束并检查现场 | 不只是停止新注入或移开手 |
| 反馈 | 帮你判断运行状态的表现 | 不会自动把内部原因完整告诉你 |
| 可复现 | 在记下的条件与容许差异内，重复出现相符结果 | 三次相符也不等于从此到处可靠 |
| 饱和 | 在当前结构与环境下，追加投入不再按原比例增加有效作用 | 不是所有法术共用的固定投料数 |
