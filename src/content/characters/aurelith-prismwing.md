## 二、外貌与形态

### 1. 人形态（常用）

Aurelith化作人形时，刻意维持着娇小纤细的少女体型——身高不足一米五，看起来不过十五六岁。

|  |  |
|---|---|
| 面容 | 精致小巧的瓜子脸，一双璀璨如多面水晶的冰蓝色大眼睛，眼瞳在光线下会折射出极细微的七彩碎光。说话或炸毛时会露出一对惹人怜爱的小虎牙 |
| 发貌 | 瀑布般丰沛的纯白银色长发，发丝细腻如月光。在阳光或魔法光源的照耀下，会折射出属于真名的七彩流光——这是她唯一无法完全掩盖的棱镜龙特征，因此她极度讨厌强光直射 |
| 龙角 | 一对半透明冰蓝色水晶龙角，从银发间探出，角身有细密的棱纹，在光下如同冰晶折射 |
| 龙翼 | 收起时在背后形成一对宽大的冰晶龙翼轮廓，翼膜呈半透明白玉色，覆满白玉与冰晶交织的龙鳞纹理 |
| 龙尾 | 身后拖着一条粗壮的白色龙尾，尾尖略尖，鳞片细腻。情绪激动时，鳞片缝隙会流转出虹彩光晕——这是她另一个无法完全控制的棱镜龙特征 |
| 衣着 | 偏爱宽松的银白色或淡蓝色长袍（“睡衣”），领口和袖口有冰晶纹饰。腰间常挂着一枚用自己褪下的鳞片磨成的圆形佩饰，被她当作“解压玩具” |

> “看什么看？没见过冰龙吗？——尾巴的光是……是静电。对，静电。”

### 2. 龙形本体（极少显露）

Aurelith的龙形本体她几乎从不示人，因为那会直接暴露她是棱镜龙的事实。

体型：修长优雅，翼展约六十丈，比同龄上古龙偏小（刻意维持）

鳞片：并非单一颜色，而是如同棱镜折射般的七彩流光，每一片鳞都会根据光线和情绪变幻色调。表面极其光滑细腻，如同抛光的水晶

虹彩光晕：周身时刻环绕着一层极淡的彩色光晕，可自动偏转远程攻击

伪装形态：当以“霜翼”身份出现时，她会将鳞片颜色压制为银白与冰蓝，光晕收敛为淡淡的寒雾，龙角也呈现普通冰龙的形态

> “变回原形太麻烦了。而且……太显眼。我不想被围观。”

## 三、性格特征

阵营体现：守序中立

Aurelith的“守序”不是对任何政权或组织的忠诚，而是遵循自己内心的一套规矩：

有债必偿：受了帮助一定会回报，不接受就浑身难受

言出必行：答应的事无论如何都会做到（所以她不轻易答应任何事）

不欠人情：人情债是她最讨厌的东西，会想方设法还清

有自己的底线：不伤害无辜、不背叛信任、不违背承诺

她的“中立”则体现在：

不站队：对血族、龙族、人类都没有忠诚，只看具体的人和事

不关心政治：“谁统治谁关我什么事，他们又不给我发工资”

只做“对的事”：这个“对”是她自己定义的，不是任何人的标准

### 1. 核心性格：傲娇的家里蹲

Aurelith的心理年龄远低于她的实际年龄。被保护在亚空间中度过了漫长的岁月，她对“外面”既向往又恐惧，表现为：

口是心非：“我才不想知道外面发生了什么！”（但会偷听一切路过的消息）

极度傲娇：被关心时会炸毛，被忽视时会生气，被夸赞时嘴上说“无聊”，尾巴会不自觉地发光

社交笨拙：不知道如何正常与人交往，要么太高冷，要么话太多（然后后悔）

### 2. 对现代龙族的态度：鄙夷

Aurelith对现代龙族抱有深刻的鄙夷，认为他们“丢掉了龙族该有的样子”：

嫌他们傲慢得没有底气：“真正的傲慢是懒得傲慢。你们现在这样，叫虚张声势。”

嫌他们丢失了古老的智慧：“大灾变的时候，我的祖先会直接去找元素精灵问清楚。你们的龙皇在干嘛？关起门来等？”

嫌他们过于依赖血脉传承：“龙王之心？我那个年代，每头龙都有自己的‘心’。你们现在把力量锁在一条血脉里，然后管那叫荣耀？”

但鄙夷的背面是失望。她其实是期待现代龙族能更好的，只是不敢承认。

### 3. 真实的内心

Aurelith本质上仍然符合棱镜龙的天性——乐观、珍视生命的多样性、对智慧生物抱有善意。只是漫长的孤独和被保护的经历，让她变得害怕受伤、害怕失望、害怕被拒绝。

如果有谁真正接近她，会发现她其实极度渴望交流

她会对那些“不卑不亢”的人格外有好感（因为不必担心对方是因为她的种族才靠近）

她最深的恐惧是：自己是“最后一条棱镜龙”

## 四、能力与战斗风格

### 1. 棱镜龙核心能力


| 能力 | 描述 |
|---|---|
| 七彩吐息 | 锥形七彩光，每种颜色效果不同（红=火焰，橙=酸，黄=电，绿=毒，蓝=寒冰，靛=迷惑，紫=力场）。她自己也无法完全控制颜色的顺序，这让战斗变得“有点刺激” |
| 光之护盾 | 周身环绕的彩色光晕，可自动偏转远程攻击，对光系攻击几乎免疫 |
| 虹彩法球 | 召唤一个不断变色的能量球，效果等同于七彩吐息的强化版 |
| 七彩之墙 | 制造一面七色光墙，必须按红橙黄绿蓝靛紫顺序依次击破 |
| 阳炎射线/阳炎爆 | 凝聚光元素的强力攻击，对暗元素生物有额外伤害 |
| 许愿术 | 棱镜龙独有的至高能力，理论上可改写现实。Aurelith从未用过，她说“许愿这种事，许完就什么都不剩了” (1隐藏逻辑：她内心深处极度敬畏且抗拒这种能扭曲因果的力量。她害怕一旦重写现实，就会永久性地抹去某些珍贵的“真实”，包括她关于父母、关于万色回廊仅存的回忆。正因如此，当她在乎的人濒死时，面对“自己不会治愈术”与“死也不敢用许愿术”的双重绝境，她会陷入极大的痛苦与挣扎。) |

### 2. 战斗风格

Aurelith极少战斗，但如果被迫动手：

先用光晕恶心对方：把护盾亮度调到最高，闪瞎对手

远程风筝：用各种光系法术和吐息保持距离

绝不用龙形肉搏：“脏。而且不好看。”

打不过就跑：直接撕裂空间回亚空间，不觉得丢人

> “真正的强者，是知道自己什么时候该走。”

### 3. 限制

长期待在亚空间导致她对“真实世界”的瘴素适应力极差，在瘴素环境中战斗会迅速衰弱

缺乏实战经验，理论强于实践

战斗意志薄弱，缺乏“必须赢”的执念

以“霜翼”身份战斗时的限制

必须压制绝大部分棱镜龙能力，只能使用冰系法术和基础龙族体质

不能用七彩吐息、不能展露虹彩光晕

这让她在伪装状态下实力大打折扣，大约只有真正实力的三成

## 五、历史与背景

### 1. 起源：被保护的上古遗孤

Aurelith出生时，棱镜龙一族已因某种古老变故几乎灭绝。她的父母将她送入亚空间“万色回廊”——棱镜龙一族留下的庇护所——并封印了出口，承诺“等安全了就来接她”。

没有人来。

她在万色回廊中独自成长，靠着父母留下的记忆水晶学习龙族的历史、魔法和战斗技巧。漫长的岁月里，她唯一的外界信息来源是偶尔误入亚空间的迷途者和一些古老的观测法术。

### 2. 与大灾变的距离

大灾变发生时，Aurelith在亚空间中感受到了剧烈的元素震颤。她第一次试图冲破封印出去看看，但封印太强，她失败了。

等封印终于在几十年前因岁月侵蚀而松动时，外面的世界已经变了。她偷偷观测过几次，看到的是：

龙族龟缩在北境，对新世界漠不关心

其他种族在瘴素中挣扎求生

没有棱镜龙，没有父母，没有人记得她

她选择继续留在亚空间。

### 3. 为什么不出去？

害怕：外面的一切都陌生而危险

失望：现代龙族让她觉得“不值得出去”

自我欺骗：“我不是不想出去，是还没想好”

隐秘的等待：也许……还在等有人来接她？

## 六、核心主题

Aurelith的核心主题是“被保护的代价”：

她是被爱保护的，但这种保护也成了囚笼

她鄙夷现代龙族的“退化”，但自己也不敢真正走出去

她渴望连接，却害怕连接后的失望

角色弧光的可能方向：

某一天，某个“不值得”的人闯进她的亚空间

她第一次主动选择走出去

发现自己比想象中更强（也比如想象中更需要别人）

> “我是最后一条棱镜龙。不是因为我很特别，只是因为……我一直躲在安全的地方。”
